Приложение для подборки вин: оценка одного вина, метрики модели при выбранном пороге, пакетное предсказание по CSV и коэффициенты модели.

Версия Python: 3.13

Установка и запуск (из папки wine_app):

```bash
pip install -r requirements.txt
streamlit run app.py
```

После запуска приложение откроется в браузере по адресу http://localhost:8501

Файлы:
app.py - код приложения
model.joblib - обученный пайплайн (StandardScaler + LogisticRegression), сохранен в scikit-learn 1.7.2
config.json - порог по умолчанию
test.csv - тестовая выборка
requirements.txt - версии библиотек

Кэширование: модель загружается через st.cache_resource, а test.csv и вероятности на тесте через st.cache_data. Модель - это один общий объект на весь сервер, который не нужно копировать и сериализовывать, поэтому для нее подходит cache_resource. Таблицы и массивы - это данные, для них cache_data сохраняет копию результата и отдает новую копию при каждом вызове, поэтому их нельзя случайно испортить. Если вызвать joblib.load без декоратора, то модель будет заново читаться с диска при каждом действии пользователя, например при каждом движении слайдера порога, и приложение будет работать медленнее.
